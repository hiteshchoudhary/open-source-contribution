# Open Source Contribution 2025

A repository created to organize and practice open-source contribution work, GitHub collaboration, and contribution-ready development habits.

## Project Overview

This repository is used as a workspace for learning how open-source contribution works. It focuses on understanding GitHub workflows, issue-based development, pull requests, documentation, and clean contribution practices.

## Purpose

The main purpose of this repository is to improve practical skills required for contributing to open-source projects, including:

- Reading project documentation
- Understanding existing codebases
- Creating meaningful commits
- Working with branches
- Opening pull requests
- Writing clear contribution notes
- Maintaining clean Markdown documentation

## Tech Stack / Tools

- Git
- GitHub
- Markdown
- Project documentation practices

## How to Use This Repository

1. Clone the repository:

```bash
git clone https://github.com/ParkhiyaParth/open-source-contribution-25.git
```

2. Go inside the folder:

```bash
cd open-source-contribution-25
```

3. Create a new branch for any contribution or practice work:

```bash
git checkout -b practice/update-docs
```

4. Make changes and commit:

```bash
git add .
git commit -m "Add contribution practice notes"
```

## Recommended Contribution Workflow

```text
Fork or clone repository
Create a branch
Make focused changes
Test the changes
Commit with a clear message
Push the branch
Open a pull request
```
