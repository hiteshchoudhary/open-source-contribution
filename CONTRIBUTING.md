
# Contributing Guidelines

Thanks for your interest in contributing to **Chai Aur Code**! 🎉
This project is open-source and welcomes contributions of all kinds — code, documentation, design, or ideas.

## Getting Started

1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:

   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
3. **Create a new branch** for your contribution:

   ```bash
   git checkout -b feature/your-feature-name
   ```

## Working with Issues

* Before starting work, **check existing issues** to see if your idea or bug is already reported.
* If it’s new, open a **new Issue** with:

  * A clear title.
  * A description of the problem or feature request.
  * Steps to reproduce (for bugs).
  * Screenshots/logs if relevant.
* Wait for maintainers/community to give feedback before starting big changes.

## Making Changes

* Follow the existing project structure.
* If you add a new feature/module, create a **new folder** (if required) and include a `README.md` inside it describing the purpose and usage.
* Keep commits small and meaningful.
* Write clear commit messages (e.g., `fix: corrected typo in README`, `feat: added new feature for XYZ`).

## Submitting Changes

1. Push your branch to your fork:

   ```bash
   git push origin feature/your-feature-name
   ```
2. Open a **Pull Request (PR)** to the main repository:

   * Clearly describe what you changed and why.
   * Reference the Issue number it closes/fixes (e.g., `Closes #12`).
   * Be open to feedback — reviews are part of the process.

## Code of Conduct

* Be respectful and constructive.
* Assume positive intent.
* Collaborate openly — suggestions and feedback are always welcome.
