JavaScript Cheat Sheet 🚀
Since you're learning JavaScript for MERN + DSA, here's a practical cheat sheet focused on the things you'll actually use.
1. Variables
let age = 20;        // can change
const name = "Adarsh"; // cannot reassign
var city = "Kanpur"; // old style

Easy trick
const = constant
let = later change
var = avoid in modern JS

let x = 10;
x = 20;       // ✅

const y = 10;
y = 20;       // ❌

2. Data Types
let name = "Adarsh";       // String
let age = 20;              // Number
let isStudent = true;      // Boolean
let x;                     // Undefined
let y = null;              // Null
let big = 123n;            // BigInt
let id = Symbol("id");     // Symbol

Check type:
typeof name;       // "string"
typeof age;        // "number"
typeof true;       // "boolean"

3. Strings
let str = "Hello JavaScript";

str.length;
str[0];

str.toUpperCase();
str.toLowerCase();

str.includes("Java");
str.startsWith("Hello");
str.endsWith("Script");

str.indexOf("Java");

4. Arrays
let arr = [10, 20, 30, 40];

Basic
arr.length;

arr[0];

arr.push(50);       // add end
arr.pop();          // remove end

arr.unshift(5);     // add beginning
arr.shift();        // remove beginning

Important methods
arr.includes(20);

arr.indexOf(30);

arr.slice(1, 3);

arr.splice(1, 2);

map() ⭐
Creates a new array.
let nums = [1, 2, 3, 4];

let doubled = nums.map(x => x * 2);

console.log(doubled);
// [2, 4, 6, 8]

filter() ⭐
Keeps elements satisfying condition.
let nums = [1, 2, 3, 4, 5];

let even = nums.filter(x => x % 2 === 0);

// [2, 4]

reduce() ⭐
Converts array into one result.
let nums = [1, 2, 3, 4];

let sum = nums.reduce((total, x) => total + x, 0);

// 10

find()
let x = nums.find(x => x > 2);

// 3

some()
nums.some(x => x > 3);
// true

every()
nums.every(x => x > 0);
// true

5. Sorting
Numbers
⚠️ Don't do:
arr.sort();

Because JavaScript sorts as strings by default.
Use:
arr.sort((a, b) => a - b); // ascending
arr.sort((a, b) => b - a); // descending

Example:
let arr = [10, 2, 30, 5];

arr.sort((a, b) => a - b);

// [2, 5, 10, 30]

9. Spread Operator ... ⭐
Array
let a = [1, 2, 3];

let b = [...a, 4, 5];

// [1,2,3,4,5]

Object
let user = {
    name: "Adarsh",
    age: 20
};

let updatedUser = {
    ...user,
    age: 21
};

Think:
... = spread/copy

10. Rest Operator ...
Looks the same but behaves differently.
function sum(...nums) {
    return nums.reduce((a, b) => a + b, 0);
}

sum(1, 2, 3, 4);

Here ...nums collects values.
Spread → expand
Rest → collect

11. Functions
Normal

    return a + b;
}

Arrow function ⭐

    return a + b;
};

Short:
const add = (a, b) => a + b;

12. Conditions

    console.log("Adult");
} else {
    console.log("Minor");
}

Ternary

Think:
condition ? true : false

13. == vs === ⭐
5 == "5";     // true
5 === "5";    // false

Remember
== → value comparison + type conversion
=== → value + type comparison

Prefer:
===

for...in

if (i === 5)

18. Sets ⭐
Useful for unique values.

// {10, 20}

Size:

Convert to array:

DSA use
Remove duplicates:

19. Map ⭐
Useful for key-value pairs and frequency counting.
let map = new Map();

map.set("apple", 5);
map.set("banana", 3);

Get:
map.get("apple");

Check:
map.has("apple");

Delete:
map.delete("apple");

Size:
map.size;

Frequency counting
let freq = new Map();

for (let x of arr) {
    freq.set(x, (freq.get(x) || 0) + 1);
}

This is very important for DSA.
20. Optional Chaining ?.
Prevents errors when something doesn't exist.
user?.address?.city

Instead of:
user.address.city

which could cause an error if address is missing.
21. Nullish Coalescing ??
let name = null;

let result = name ?? "Guest";

console.log(result);
// Guest

Means:
If left side is null or undefined, use right side.

34. Common DSA Patterns
Frequency
const freq = {};

for (const x of arr) {
    freq[x] = (freq[x] || 0) + 1;
}

Two Pointer
let left = 0;
let right = arr.length - 1;

while (left < right) {

    if (arr[left] + arr[right] === target) {
        // found
    }

    if (arr[left] + arr[right] < target)
        left++;
    else
        right--;
}

Sliding Window
let left = 0;
let sum = 0;

for (let right = 0; right < arr.length; right++) {

    sum += arr[right];

    while (sum > target) {
        sum -= arr[left];
        left++;
    }
}
